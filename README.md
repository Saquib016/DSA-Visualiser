# DSA Visualizer

An interactive Data Structures and Algorithms Visualizer designed to help students understand algorithms through real-time animations and visual demonstrations.

## Features

* Sorting Algorithms Visualization

  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Quick Sort

* Searching Algorithms

  * Linear Search
  * Binary Search

* Graph Algorithms

  * BFS
  * DFS

* Pathfinding Algorithms

  * Dijkstra's Algorithm
  * A* Search

* Adjustable animation speed

* Interactive user controls

* Responsive UI

## Tech Stack

* HTML
* CSS
* JavaScript

## Purpose

This project was built to make learning Data Structures and Algorithms more intuitive by visualizing how algorithms work step-by-step.

## Future Improvements

* Tree Visualizations
* Trie Visualizer
* Dynamic Programming Visualizations
* Algorithm Performance Comparison
* And Lots Of New Features will be introduced later
## Run Locally

1. Clone the repository
2. Open `index.html`
3. Start visualizing algorithms
